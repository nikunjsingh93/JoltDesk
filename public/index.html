Saved APIs
Paste your server API URL. A web UI URL such as http://host:8080 is accepted too.
Auto context uses the running server limit when available. Native/training limits are estimates. Auto output leaves the generation limit to your server.
For Splash: blank uses the server default. A budget such as 2048 limits thinking and leaves the remaining output for the answer. Applies to new replies on this API.
Pi-Bolt engine

Checks on startup and every 6 hours while open. Updates install when you choose and your chats are idle.
Added to every chat as an AGENTS.md file. Each chat also reads AGENTS.md, or CLAUDE.md, from its project folder and the folders above it.
Skills
A skill is a folder with a SKILL.md file. The agent reads a skill when a request matches its description, or when you type /skill:name. Automatic use needs Read files or a higher permission. Turn on a project's own skills from the Files tab.
Advanced engine settings

Existing CLI settings and keys are kept intact.

Reasoning shows provider-exposed summaries. Live token estimates become reported usage when available.

Worker models

Choose up to three workers for this chat. They can answer questions in parallel in any chat. For project edits, they work in separate Git worktrees.

Worker results

Question workers use only the information the lead gives them and have no file or web tools. Coding workers need Ask or Bypass and a clean Git project with a commit; worktrees do not include ignored files. Coding workers inherit the chat’s permissions. Worktrees are not a sandbox.
